# Music Player 2

A sleek and modern web-based music player built with HTML, CSS, and JavaScript. This player allows you to enjoy your favorite tracks with an intuitive interface, featuring playlist management, audio controls, and a responsive design.

## Features

- **Play/Pause**: Control playback with a single click.
- **Skip Tracks**: Navigate to the next or previous song in the playlist.
- **Shuffle**: Randomize the order of songs.
- **Repeat**: Loop a single song or the entire playlist.
- **Volume Control**: Adjust volume with a slider and mute option.
- **Seek Bar**: Scrub through the current track.
- **Playlist**: View and select songs from a sidebar playlist.
- **Dynamic Background**: Background changes based on the current song's album art.
- **Responsive Design**: Works on desktop and mobile devices.

## How to Use

1. Clone or download the repository.
2. Open `index.html` in your web browser.
3. Click the play button to start listening.
4. Use the playlist button (queue_music icon) to open the sidebar and select songs.
5. Adjust volume, shuffle, repeat, and seek as needed.

## Technologies Used

- **HTML**: Structure and markup.
- **CSS**: Styling and responsive layout.
- **JavaScript**: Interactive functionality and audio handling.

## Project Structure

- `index.html`: Main HTML file.
- `style.css`: CSS styles.
- `script.js`: JavaScript logic.
- `assets/images/`: Album cover images.
- `assets/music/`: Audio files (MP3 format).
